Communication 通信框架指南

autolink 是Autonomy的分布式通信运行时，为规划、控制、定位、地图等模块提供 Node / Channel / Service / Action 等通信原语，底层支持进程内、共享内存与 RTPS 等多种传输后端。本文档为模块总入口，以下按 §1–§9 顺序组织。
