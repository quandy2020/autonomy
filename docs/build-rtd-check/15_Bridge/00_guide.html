Bridge 通信桥接指南

autonomy/bridge 是 Autonomy 的外部通信桥接子系统，在机器人本地导航栈与外部客户端（移动端、云平台、调度系统）之间提供统一 RPC / 消息通道。本文档为模块总入口，以下按 §1–§8 顺序组织。
