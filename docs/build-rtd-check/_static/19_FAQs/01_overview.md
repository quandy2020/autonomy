# 1. FAQ 概览

### 1.1 如何使用本章

1. 按**现象**在下方索引中定位章节
2. 优先查阅对应模块的 `08_troubleshooting.md`（安装/运行章已有结构化表格）
3. 本章补充**跨模块**与**历史遗留**问题（如 Cyber → Autolink 迁移）
