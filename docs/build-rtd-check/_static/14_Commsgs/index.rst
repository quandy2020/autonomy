Commsgs 通信消息
==================

`autonomy/commsgs` 是 Autonomy 的**通信消息**子系统，在 ROS 2 `common_msgs` 语义基础上提供 C++ 原生 struct 与 Protocol Buffers 双层消息定义。文档按 **§1–§9** 编号排列。
