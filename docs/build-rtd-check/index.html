Autonomy

Autonomy 是一套面向移动机器人的 C++ 导航与自主系统框架，涵盖通信、定位、建图、规划、控制、感知与仿真等模块。

快速开始

克隆仓库并进入文档目录：

git clone --recurse-submodules https://github.com/quandy2020/autonomy.git
cd autonomy/docs && python3 -m sphinx -b html source build
