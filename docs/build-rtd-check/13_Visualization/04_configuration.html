4. 配置说明

可视化专用配置位于 config/visualization/visualization.lua。

注意：该文件尚未被 config/autonomy.lua 引用，运行时 C++ 侧也无对应的 LoadOptions 解析。以下为设计配置，供未来 VisualizationServer 接入参考。

4.1 服务器参数

字段

默认值

说明

server_name

"AutonomyViewer"

"0.0.0.0"

8765

WebSocket 端口

与 Docker AUTONOMY_PORTS 默认 8765:8765 对齐。
