1.4 设计原则

  1. Server 模式：各子系统以 *Server 类对外，内部可持有 autolink Node

  2. 配置驱动：Lua → Protobuf → *Options → Server 构造

  3. 插件化算法：规划器、控制器、BT 节点以 .so 动态加载

  4. Nav2 语义对齐：接口与话题/Action 命名尽量与 Navigation2 一致

  5. 可独立运行：不强制 ROS 2；commsgs 提供消息兼容
