1.2 推荐路径

当前 libautonomy 主路径不依赖 ROS 2。新用户建议：

02 Installation 编译
    → autonomy_nav_test（§4）
    → 确认 Navigation succeeded
    → 再按需接入 ROS 2 / Bridge

1.3 运行时组件

system::Autonomy 启动后持有：

组件

职责

MapServer

加载静态地图 → costmap

PlannerServer

全局路径规划

ControllerServer

局部跟踪、里程计

TransformServer / tf_buffer

坐标变换

Navigator（BT）

任务编排（若 Configure 启用）

1.4 配置入口

--configuration_directory=config
--configuration_basename=autonomy.lua

主配置 config/autonomy.lua 聚合 map / planning / controller / navigator 等子配置。
