Autonomy 入门指南

Autonomy 是面向移动机器人的自主导航软件框架：模块化 C++ 库、Lua 配置、行为树任务编排、完整 2D 导航栈，并可与 ROS 2 消息生态及 gRPC 桥接层互操作。本文档为全书总入口，按 §1–§8 组织。
