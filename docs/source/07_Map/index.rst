Map 地图模块
============

`autonomy/map` 是 Autonomy 的**环境地图**子系统，提供静态地图服务、2D 代价地图（Costmap2D）与 2.5D 多层栅格地图（GridMap）。文档按 **§1–§8** 编号排列。
