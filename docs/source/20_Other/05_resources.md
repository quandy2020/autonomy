# 5. 外部资源

对照 Nav2、BehaviorTree、gRPC 等外部文档，需要稳定链接集合；集成行为仍以本仓库 launch 与 `DESIGN.md` 为准。

外部资料用于**概念对照**，不要当成 Autonomy 已实现的清单；Bridge 联调以 `automsgs/proto/rpcs` 为契约。
