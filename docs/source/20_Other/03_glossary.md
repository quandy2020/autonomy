# 3. 术语表

| 术语 | 说明 |
|------|------|
| Autonomy | 本导航框架 |
| Autolink | 通信中间件 |
| commsgs | Protobuf 消息层 |
| Navigator / BT | 行为树编排 |
| Task | 导航任务（非 `common::Task`） |
| Costmap / TF / Plugin | 代价图 / 坐标变换 / 动态插件 |
| Bridge | 对外 gRPC 桥 |
| Nav2 | 主要类似 |

| 帧 | 典型值 |
|----|--------|
| `global_frame` | `map` |
| `robot_base_frame` | `base_link` |
| `odom_frame` | `odom` |
