# Vista：增量可见性图规划器

Vista 位于 `autonomy/planning/planner/vista/`，由 PlannerServer 持有并复用。
探索策略通过 `PathProvider` 查询路线、距离和图证据，不创建第二份规划图。
它保留 FAR 的障碍轮廓与可见性图思路，并接入 Autonomy 原生地图读取和规划接口。

## 地图边界

`autonomy/map` 的源码、接口与消息保持原样。`NativeCostmapReader` 在原有
Costmap 锁内复制尺寸、原点、分辨率和栅格，释放锁后生成消费者自己的
`MapReadView`。该视图是读取副本，不是另一套权威建图模块。

二维投影用于路线连通性。`has_height_evidence=false` 明确说明该读取结果不能
证明桌底净空、机器人全身安全或地面支撑，执行必须使用原始三维观测。
`footprint_inflated` 用于避免重复施加机器人半径和水平安全裕度。

## 增量更新

一次数据流为：已有地图锁定复制 → `MapReader` 比较变化 → `dirty_regions`
→ 轮廓顶点更新 → 空间索引查询受影响边 → 重新校验并查询路线。

1. 位姿对齐发生变化时提高 `map_epoch`，清除旧图及空间索引。
2. 同一坐标世代内只有连续几何版本可以使用局部变化区域；跳过版本、缺少变化区域或地图范围改变时，全域复核当前与上一范围。
3. 变化区域外扩机器人半径、安全裕度及栅格误差范围。
4. 保留仍匹配的顶点 ID，移除失效顶点及其关联边，加入新轮廓顶点。
5. 用边包围盒空间索引查找受影响边，重新检查碰撞与 clearance。无向边必须在两个执行方向上都通过原有几何检查。
6. 保留被阻塞边的空间索引信息；障碍物移开时这些边仍会进入复验。
7. 将地图的实际观测前缀和恢复基线转交给图证据。

几何没有变化时也更新 `observation_cut`、`observation_baseline` 和
`observation_recovery_generation`。新观测已被融合并不一定改变障碍轮廓，
因此不能只依靠几何版本判断观测是否已进入规划图。

## 版本缺口与失败处理

`dirty_regions` 描述相邻几何版本的差分。如果消费者最后应用 revision 1，
下次收到 revision 3，就不能只用 revision 3 相对 revision 2 的差分。
`GraphUpdater` 在这种情况下复核所有保留边及当前轮廓，包含仍被阻塞的边；
匹配的顶点继续使用原 ID。`GraphUpdateStats.full_refresh` 记录全域更新，
连续局部更新则保留空间索引查询，几何不变时只转交观测证据。

同一 epoch 内，frame、分辨率、膨胀语义、高度证据类型与网格对齐关系
必须一致；改变这些契约需要新 epoch。非有限或倒置的变化区域在修改图之前
拒绝，已有有效图保留。图更新内部异常则清空空间状态并暂停路线输出，
后续成功更新重新建立图；不能继续用部分更新的图或旧自由空间授权路线。

## 空间索引数值边界

桶坐标使用有符号 64 位整数，转换之前检查数值范围及矩形跨度；单条边的
索引成员数最多为一百万。非法边替换在删除旧成员之前拒绝，分配失败也撤销
新增成员而保留原条目。宽范围查询不枚举无界空桶，改为遍历已保存包围盒
并精确过滤；负坐标、接触边界和巨大但有限的查询范围均有专项回归。

轮廓提取先把世界区域裁剪到当前地图，再转换为栅格下标，避免巨幅区域导致
浮点转整数溢出。邻域索引使用宽整数计算，越界点直接作为非自由区域。

## 路线与探索完成的区别

图节点数和边长度有显式上限。达到候选上限时记录
`candidate_limit_reached`，不能把采样不完整解释为没有剩余探索区域。
探索完成还需独立的栅格连通性复核、公平候选遍历和实际观测确认。

图证据来自 PlannerServer 持有的实际实例。它必须覆盖完成请求固定的
观测前缀；地图随后出现的新输入尾部不应让已固定的请求无限等待。
探索端不能通过队列清空或提高版本号自行生成融合回执。

## 相关实现与验收

- `native_costmap_reader.hpp/.cpp`：原有地图的有界锁定读取。
- `graph_updater.hpp/.cpp`：顶点保留、变化区域更新与边失效/恢复。
- `spatial_index.hpp/.cpp`：边空间查询。
- `visibility_graph.hpp`：图身份、几何版本及源观测前缀。
- `vista_planner.hpp/.cpp`：原生规划器接入。
- `native_vista_test.cpp`、`vista_server_test.cpp`：实际地图与服务器消费者检查。
- `incremental_graph_test.cpp`：跳过版本、差分缺失、索引替换拒绝、数值边界、契约预检、局部失效与重连、地图范围变化。

三维执行校验见 [SanD 执行安全](../09_Control/controller/08_sand_execution_safety.md)。
