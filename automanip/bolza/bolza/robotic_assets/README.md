# robotic_assets（测试用）

与 OCS2 `ocs2_robotic_assets` 同布局的最小子集，供 pinocchio 单测使用：

- `resources/anymal_c/urdf/anymal.urdf`
- `resources/mobile_manipulator/mabi_mobile/urdf/mabi_mobile.urdf`

来源：[leggedrobotics/ocs2_robotic_assets](https://github.com/leggedrobotics/ocs2_robotic_assets)。完整网格等资源仍可通过 `-DBOLZA_ROBOTIC_ASSETS_ROOT` 指向完整克隆。
